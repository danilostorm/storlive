# StorLive 0.1.0

Primeira versão desktop focada exclusivamente em captura e multi-live.

## Principais recursos

- Windows x64 portable com libobs/OBS 30.0.2 embutido, sem instalação do OBS Studio.
- Linux `.deb` para Debian/Ubuntu usando libobs e obs-plugins do sistema.
- Captura de jogo, janela, monitor/tela, webcam, microfone e áudio do computador.
- Preview real da cena Gameplay.
- Editor das propriedades de fonte expostas pelo OBS.
- Mostrar/ocultar, mutar/desmutar e remover fontes.
- Layout inicial automático para captura principal e webcam em sobreposição.
- Saída 1080p/720p, 30/60 fps e bitrates configuráveis.
- H.264 automático, hardware ou x264 + AAC.
- Multi-output RTMP com encoder compartilhado por perfil e reconexão independente.
- YouTube, Twitch, Kick, Facebook e RTMP customizado.

## Pacotes

As Releases oficiais incluem o ZIP portable Windows, o `.deb` Linux e `SHA256SUMS.txt`.

Nenhuma stream key do sistema legado é incluída no projeto ou nos pacotes.
