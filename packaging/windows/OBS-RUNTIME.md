# StorLive Windows runtime

The Windows portable package embeds the runtime components required from OBS Studio/libobs 30.0.2. They are downloaded from the official OBS Project GitHub release during CI and are not stored as binaries in this repository.

StorLive and OBS Studio/libobs are distributed under GPL-2.0-or-later.

Upstream source: https://github.com/obsproject/obs-studio/tree/30.0.2
Upstream release: https://github.com/obsproject/obs-studio/releases/tag/30.0.2
