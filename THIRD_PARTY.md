# Third-party components

StorLive links to and redistributes selected components from OBS Studio/libobs in the Windows portable package.

OBS Studio / libobs
- Project: https://github.com/obsproject/obs-studio
- Runtime baseline: 30.0.2
- License: GPL-2.0-or-later

The OBS binaries are downloaded from the official OBS Project GitHub release during CI. They are not committed to this repository. StorLive source remains available in this repository under GPL-2.0-or-later.
